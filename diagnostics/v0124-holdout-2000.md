# Proposed v0.12.4 soft RB–WR balance holdout

Fresh paired holdout: 2,000 complete profile-driven 10-team drafts per arm. Trial seeds 10,001–12,000 were identical between arms; the baseline used the preserved v0.12.3 source and the proposal used the same source plus the one calibration adjustment below. The 331-player pool, historical profiles, current football data, live owner adaptation, and PWA/update files were unchanged.

## Formula under test

Inside `rosterUtility`, after the existing RB count term and contingent-RB term:

```js
const imbalance=Math.max(0,n-(c.WR||0)-1);u-=6*imbalance
```

This is a soft adjustment. It does not impose a cap or quota, and it is zero whenever existing RB depth is no more than one player ahead of WR depth.

## Conclusion

The holdout supports the calibration. It reduces early RB concentration by 4.0 percentage points at the requested R6 threshold and reduces the exact problematic construction by 1.85 points, while preserving final RB/QB/WR/TE/K/DST averages, TE/QB timing, bye concentration, legal starter completion, and recommendation-label behavior. No broad RB suppression is visible.
