# DA BOYZ Draft Assistant

GitHub Pages deployment for **DA BOYZ Draft Assistant v0.12**.

This repository hosts the Android/PWA deployment candidate. The football model and draft UI remain the validated v0.12 build; hosting changes only how the app is delivered.

Expected Pages URL: `https://avodado.github.io/da-boyz-draft-assistant/`

After Pages is enabled and `app.html.gz` is uploaded, open the Pages URL once online, install it from Chrome, then turn networking off and relaunch the installed app to verify offline operation.
